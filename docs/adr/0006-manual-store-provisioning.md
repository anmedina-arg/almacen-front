# Alta de Stores: provisioning manual, no self-service

Con solo dos Stores (Market del Cevil y el cliente nuevo), se optó por que el `Platform admin` dé de alta cada Store nueva manualmente (registro en `stores`, membership del dueño, archivo de feature flags, config de WhatsApp) en lugar de construir un flujo de self-service signup (planes, validación, límites). Se revisará cuando el volumen de Stores lo justifique.
